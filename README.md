# HTML Product Card

## Explanation

This program creates a simple product card using HTML.

The product card displays a product name image description price availability and an action button.

## Problem Statement

Create an HTML webpage that displays product information in a simple product card format.

## Features

- Displays product name
- Displays product image
- Displays product description
- Displays product price
- Displays product availability
- Provides Add to Cart button

## How It Works

The <div> element groups all product information together.

The <h2> element displays the product name.

The <img> element displays the product image.

The <p> elements display product details.

The <strong> element highlights important information.

The <button> element creates an Add to Cart button.

## Technologies Used

- HTML5
- Web Browser

## HTML Tags Used

- <div> - Groups product content
- <h1> - Main heading
- <h2> - Product heading
- <img> - Displays product image
- <p> - Displays product information
- <strong> - Highlights important text
- <button> - Creates a button

## Attributes Used

- src - Specifies the image source
- alt - Provides alternative text
- width - Sets image width
- height - Sets image height
- type - Specifies button type
